# Análise Estrutural de Redes Urbanas com OSMnx, NetworkX e Gephi

A escolha do local para o projeto foi o da região de Natal, pois o grupo tem o interesse de usar as informações aplicadas nesse trabalho na composição de outra ferramenta para a aréa da sáude de Natal.

## Objetivo
Analisar a estrutura da malha viária usando grafos.

## Metodologia
- OSMnx para coleta
- NetworkX para métricas
- Gephi para visualização

## Métricas
- Grau
- Betweenness
- Closeness
- k-core

## Resultados
- Identificação de hubs
- Regiões densas
- Pontos críticos
